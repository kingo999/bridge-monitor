# Local Codex/GPT role assignment

The provider-specific assignment formerly in the shared operating agreement is
kept here: GPT provides architecture guidance and review through
`consult_architect` and `review_implementation`; Claude Code implements and tests.
The human architect decides architecture and any change to an agreed design.

The shared duties, consultation triggers, provenance requirements and approval
boundaries remain in `docs/architecture/operating-agreement.md`. The shared
agreement now names the human-selected architecture agent rather than a provider.
One agent holding both roles does not create an independent review.

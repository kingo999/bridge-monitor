## Review focus

1. Crash between subprocess exit and final receipt: report uncertain/interrupted; retain before/after evidence, never infer completed.
2. Dirty ignored source change after review or before resume: invalidate evidence; reject mismatched resume before launch.
3. Corrupt/partial/oversized receipts and denied writes: fail explicitly without losing authoritative old record or launching unrecorded jobs.
4. Concurrent bridge instances and linked/path-escaping stores/contracts: reject safely without interfering with active jobs or external files.
5. Hostile CLI result/denial metadata: allowlisted scalar counters only; no prompts, results, stdout/stderr or denied input in durable bytes.

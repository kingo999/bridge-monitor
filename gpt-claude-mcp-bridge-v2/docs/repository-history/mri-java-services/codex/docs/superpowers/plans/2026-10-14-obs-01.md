## Global constraints

- Writes only under C:/AI/gpt-claude-mcp-bridge-v2/tools/agent-observability/; this plan is read-only for the implementer.
- C:/AI/gpt-claude-mcp-bridge-v2/ and C:/AI/gpt-claude-mcp-bridge/ are read-only references. Do not change either, any registration/configuration, live state, credentials, hooks or permissions.
- Default state source: Path.home() / '.gpt-architect-bridge-v2'; CLI override --state-dir; server binds 127.0.0.1, default port 8089 with --port override. Changing ports must not open a network interface.
- Reads restricted to telemetry/calls.jsonl, telemetry/calls.[1-5].jsonl and inflight/*.json. No registry/admin commands, Codex rollouts, prompts, answers or arbitrary filesystem endpoints. Inspect actual source markers to define a safe metadata projection; do not echo paths/prompt/error prose.
- Refuse links/junctions and non-regular source files; bound file, line, record and marker reads. Missing/malformed/truncated/oversized data must be visible and cannot silently imply a complete accounting stream.
- Keep schema-1 raw counters labelled session cumulative for observed CLI 0.162.1. Unsupported CLI/schema accounting basis is unknown. Output reasoning counts are a subset, not additive token cost.
- Fresh observed thread may use zero baseline only when explicitly resumed=false. Unknown first resumed call has no baseline. Derive subsequent per-call estimates only within matching repo/thread/model/session with valid monotonic counters and no observed inference-started failures, unknown records, conflicts or parse/truncation gaps. Invalidate across ambiguity. Never sum cumulative rows. Even eligible deltas are telemetry-derived interval estimates: missing writes/external turns cannot be ruled out from these logs alone; show this limitation.
- Never infer billed cost, subscription balance or context-window size from usage. Missing fields remain null, not zero. Ratios require known positive denominators.
- Durations: run_ms is subprocess execution; ended_at-started_at is end-to-end observation; queue_ms separate. Invalid timestamps/counters are unknown.
- Server only fixed GET endpoints; no mutation/admin controls, CLI execution or arbitrary path serving. Reject write methods, untrusted Host/Origin and traversal; no CORS relaxation. Use textContent/escaping, CSP and nosniff headers.
- Active markers are observed states, not proof of a live process. Display phase/elapsed/uncertainty; do not claim exact agent reasoning or tool activity.
- Test fixtures/workspaces must inherit ACLs (plain mkdir) if tempfile.mkdtemp fails in Windows sandbox; never alter security settings to run tests. Do not touch real home settings for tests.

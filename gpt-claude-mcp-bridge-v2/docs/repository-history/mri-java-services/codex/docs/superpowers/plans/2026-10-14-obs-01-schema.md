Source: bridge/service.py admission and observer callbacks; bridge/state.py write_marker(). Files live in inflight/*.json. Markers are NOT CLI or model session logs and contain no prompt/answer.

Updates may add thread_id and process metadata and set phase=turn_completed; stale or cancelled records can be state=uncertain with reason and since. Safe UI projection should contain only call_id/thread_id/model, state/phase/ownership, started_at or since, safe reason code, elapsed observation. No process execution/liveness probe.
